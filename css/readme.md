# CSS Learning Repository

## Overview

This repository tracks the progression of mastering Cascading Style Sheets (CSS), covering everything from fundamental selectors to advanced animations. The codebase is referenced from the html.zip archive.

## Core CSS Concepts Mastered

* **CSS Integration & Units:** Implementation of Inline, Internal, and External CSS coding methods, alongside practical usage of Absolute and Relative CSS units.
* **Selectors:** Deep dive into CSS targeting using Simple, Attribute, Combinator, Pseudo-class, and Pseudo-element selectors.
* **Box Model & Layout:** Practical application of the CSS Box Model, content overflow management, and advanced layout structuring using the Display property and Flexbox.
* **Backgrounds & Borders:** Comprehensive styling using Background (Attachment, Clip, Color, Image) and Border properties, including complex Circular and Elliptical radii.
* **Typography:** Customizing text rendering using Font Family, Font Text properties, and Text Shadows.
* **Visual Effects:** Enhancing UI elements using Box Shadow, Filter, Backdrop Filter, and Clip Path properties.
* **Positioning:** Controlling document flow and element stacking using standard Position properties and Z-Index.
* **Responsiveness:** Adapting layouts for different screen sizes and print formats using Media Queries.
* **State & Motion:** Creating dynamic web pages using Transform, Transition, and advanced Animation properties (including Animation Direction and Fill Mode).

## Mini-Projects & Practical Applications

* **UI Components:** Designed specialized components like a Glowing Button, a Lotus Flower utilizing Z-Index, and an iPhone 15 Pro mockup.
* **Animations:** Developed custom keyframe animations including an Ashoka Chakra Rotation, Ashoka Chakra Shadow Rotation, Gallery Images Animation, Rainbow Heading, and Vehicle/Planet image transitions.
* **Thematic Layouts:** Constructed interactive layouts such as "The Earth Task", "Vishnu God Animation", and an interactive "Explore Button".
* **Iconography & Graphics:** Recreated complex visuals using pure CSS, including Google Doodles, the Google Gemini logo, Flower Petals, and an Instagram Icon.
* **Data Presentation:** Styled structured data elements such as a Population Graph, a Blood Group Table, and a WOW Table.
