# HTML Learning Repository

## Overview

This repository showcases my progress, practical exercises, and projects created while mastering HTML.

## Key Concepts Mastered

* **Boilerplate & Basic Tags:** Setting up foundational HTML document structures and utilizing basic tags.
* **Text Formatting & Iframes:** Applying text formatting elements and embedding external content using inline frames.
* **Divisions & Layouts:** Organizing page content using `div` tags, demonstrated by constructing various country flags [India, Italy, Norway].
* **Interactive Elements:** Using the `details` tag for collapsible content and HTML entities for rendering special characters.
* **Web Forms:** Designing structured user input areas, including functional replicas of a Facebook login and user registration forms.
* **Data Organization (Lists):** Implementing ordered, unordered, and description lists to structure domain and purpose data.
* **Tables:** Constructing complex grid layouts for batch schedules, board game catalogs, and student mock ratings.
* **Hyperlinks & Navigation:** Creating interconnected site navigation across multiple themed pages [Blue, Green, Red].
* **Multimedia:** Embedding and configuring audio, video, and image files within web pages.
* **Animations:** Utilizing the legacy `marquee` tag to create moving elements, such as a 3D scrollable basketball.
* **Semantic HTML:** Differentiating between semantic and non-semantic tags to build accessible, modern page structures modeled after W3Schools.
